# 🚀 FinnMarket - Norwegian Marketplace Prototype (Finn.no Architecture)

تطبيق منصة إعلانات مبوبة وسوق إلكتروني متكامل مصمم بأعلى معايير التصميم الاسكندنافي النظيف (Scandinavian UI/UX)، مستوحى من موقع **Finn.no** النرويجي المعتمد على القطاعات الرئيسية (العقارات، السيارات، المستعمل، الوظائف، والمنتجات المجانية Gis bort).

---

## 🌟 الميزات المكتملة في المشروع

1. **الهوية والتصميم الاسكندنافي (Scandinavian UI)**:
   - نظام ألوان متناسق مع التجاوب مع اتجاه الكتابة العربي (RTL) والأجهزة المختلفة.
   - خطوط حديثة (`Cairo` و `Inter`) مع تأثيرات Glassmorphic و Micro-animations.

2. **التصفية المتعددة الفورية (Faceted Search & Filter Engine)**:
   - فلترة لحظية حسب القطاع، المدينة، نطاق السعر، الكلمات المفتاحية، وحالة المنتج.
   - تبديل العرض بين الشبكي (Grid View) والقائمة (List View).

3. **القطاعات المدمجة (Marketplace Verticals)**:
   - 🏡 **العقارات (Eiendom)**
   - 🚗 **السيارات والمركبات (Bil)**
   - 🛋️ **سوق المستعمل والأثاث (Torget)**
   - 💼 **الوظائف (Jobb)**
   - 🎁 **الإهداء المجاني (Gis bort)**

4. **المفضلة والمحادثات المباشرة (Favorites & Live Chat)**:
   - حفظ الإعلانات في المفضلة بضغطة زر وتحديث الإحصائيات في LocalStorage.
   - نافذة محادثة مباشرة تفاعلية بين المشتري والبائع.

5. **معالج إضافة إعلان جديد (Post Ad Wizard)**:
   - نموذج تفاعلي متكامل يتيح نشر الإعلانات فوراً مع التخزين المحلي.

6. **قواعد البيانات (Supabase PostgreSQL Integration)**:
   - يشتمل المشروع على ملف `supabase_schema.sql` كامل وجاهز للرفـع على مشروع Supabase لإنشاء الجداول، الفهارس السريعة، وأمان RLS.

## 🛠️ كيفية التشغيل

شغّل المشروع عبر خادم محلي (مثل `npx serve`). لا يُنصح بفتح `index.html` مباشرة لأن المصادقة وقيود المتصفح تعمل بصورة صحيحة عبر HTTP فقط.

## قاعدة البيانات

ملف `supabase_schema.sql` يمثل المخطط الأساسي التاريخي. إصلاحات الإنتاج والأمان موجودة كترحيلات مرتبة داخل `supabase/migrations` ويجب تطبيقها بعد المخطط الأساسي. لا تضع مفتاح `service_role` في الواجهة؛ المفتاح المنشور الحالي Publishable ومصمم للاستخدام مع RLS.

# FinnMarket

منصة إعلانات مبوبة عربية للسعودية مبنية بواجهة HTML/CSS/JavaScript وقاعدة Supabase. تعرض إعلانات حقيقية من قاعدة البيانات ولا تستخدم بيانات تجريبية عند تعطل الخدمة.

## الوظائف

- تسجيل حساب وتسجيل الدخول واستعادة كلمة المرور عبر Supabase Auth.
- نشر الإعلان وتعديله وحذفه ورفع حتى 15 صورة محسّنة للويب.
- بحث كتابي وقائمة إعلانات وأقسام ومدن المملكة.
- مفضلة ومحادثات خاصة وتعليقات وتقييمات وبلاغات.
- إظهار وسيلة التواصل للمستخدم المسجل فقط.
- ملف شخصي وصورة حساب وطلب حذف الحساب والبيانات.
- لوحة إدارة للإعلانات والأعضاء والبلاغات وطلبات حذف الحساب.
- RLS وRPCs محكومة وترويسات أمان وملفات SEO وصفحات خصوصية وشروط.

## التشغيل المحلي

```bash
npm ci
npm run check
npm test
npx serve .
```

لا تفتح ملفات HTML مباشرة؛ المصادقة وسياسات المتصفح تحتاج خادم HTTP.

## قاعدة البيانات

- `supabase_schema.sql` هو المخطط التاريخي الأساسي.
- التغييرات المتتابعة داخل `supabase/migrations`.
- طبّق الترحيلات المتوافقة قبل نشر واجهة تعتمد على RPC جديدة.
- لا تضع مفاتيح `service_role` أو `sb_secret_` في الواجهة. المفتاح المنشور للمتصفح Publishable ويعتمد على RLS.

## التحقق والنشر

- `npm run check`: تحليل JavaScript المضمّن والخارجي وفحص diff.
- `npm test`: اختبارات الأمن والسلوك وUX وSEO.
- GitHub Actions يشغّل الاختبارات على Pull Requests ويفحص توافر الإنتاج دوريًا.
- راجع [OPERATIONS.md](OPERATIONS.md) للتراجع والمراقبة والنسخ الاحتياطي والاستجابة للحوادث.
